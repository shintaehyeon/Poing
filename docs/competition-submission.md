**1차 심사 제출 마감: 2026년 9월 21일(월) 16:00 정각.** 마감 후 수정할 수 없다.

## 1. 제출 전 필수 확인

- [ ] 팀명과 최종 팀원 정보를 확인한다.
- [ ] 로그인 없이 전체 핵심 흐름을 테스트할 수 있게 한다.
- [ ] 외부에서 접속 가능한 Vercel 운영 URL을 제출한다.
- [ ] 시크릿 브라우저에서 운영 URL의 랜딩부터 여행 기록까지 테스트한다.
- [ ] 실제 서비스에서 호출되는 한국관광공사 OpenAPI만 제출한다.
- [ ] API 신청자별 인코딩 키와 디코딩 키를 모두 준비한다.
- [ ] 운영계정 신청 여부를 결정한다. 신청은 선택 사항이며, 신청한다면 실제 사용하는 대표 API 1개만 선택한다.
- [ ] Vercel 로그와 공공데이터포털 호출 건수로 실제 호출을 확인한다.
- [ ] 대표 이미지 1장과 상세 이미지 3~5장을 준비한다.
- [ ] 공식 기능설명서 양식에 내용을 옮겨 작성하고 PDF로 변환한다. 이 Markdown 초안 자체를 제출하지 않는다.
- [ ] 공모전 참가 신청 계정의 이메일 인증과 최종 팀원 입력을 마친다.

> 심사에서는 제출한 인증키로 개발 기간 내 호출 건수와 서비스 내 활용 여부를 확인한다. 시험 호출만 한 API나 화면에 이름만 표시한 API는 제출 목록에 포함하지 않는다.

## 4. 대표 운영계정 신청안

운영계정 신청은 **선택 사항**이다. 신청하지 않아도 제출 자체가 막히지는 않지만, OpenAPI의 실제 호출 내역과 서비스 내 활용은 반드시 확인 가능해야 한다.

- 대표 API: `한국관광공사 국문 관광정보 서비스_GW`
- 서비스명: `POING`
- 서비스 형태: 국내 웹 서비스
- 서비스 URL: 배포 후 공개 Vercel URL
- 신청 시점: 개발 완료 및 공개 URL 확인 후, 1차 심사 접수 마감 전
- 첨부 이미지: 실제 운영 화면 캡처

### 운영계정 활용 사례 문구

> [공모전 웹·앱 개발 부문 제출 서비스] POING은 경상북도 포항시를 북포항, 구도심, 남포항, 힐링권역으로 나누고 사용자의 동행, 여행 목적, 체류 시간과 이동 수단에 맞춘 여행 일정을 제공하는 반응형 웹 서비스입니다. 한국관광공사 국문 관광정보 OpenAPI의 포항 관광지 목록, 상세 소개, 운영 정보, 주소, 좌표와 이미지를 일정 생성, 명소 탐색, 추천 근거 화면에 활용합니다. 이용자는 로그인 없이 전체 여행 생성 흐름을 테스트할 수 있으며, 생성된 일정은 지도 기반 여행 진행과 장소 변경, 여행 기록 기능으로 이어집니다.

## 5. 인증키 제출 절차

1. 공공데이터포털에 로그인한다.
2. `마이페이지 > 데이터 활용 > Open API > 인증키 발급현황`으로 이동한다.
3. API 신청자별 인코딩 키와 디코딩 키를 모두 확인한다.
4. 실제 서비스에서 사용한 API와 해당 신청자의 키만 제출한다.
5. 여러 팀원이 서로 다른 API를 신청했다면 각 신청자의 키를 모두 제출한다.

## 7. 최종 증빙 테스트

1. `/api/tour/pohang/status`에서 연결 상태를 확인한다.
2. `/api/tour/pohang/places`에서 실제 관광공사 응답을 확인한다.
3. `/plan/confirm`에서 API 데이터가 일정에 반영되는지 확인한다.
4. `/insight`에서 API 출처, 활용 화면, 실제 응답 여부를 확인한다.
5. Vercel 실행 로그와 공공데이터포털 호출 건수를 함께 확인한다.
6. 시크릿 브라우저에서 제출 URL을 처음부터 끝까지 다시 테스트한다.

## 8. 공식 공지에서 확인한 추가 유의사항

- 기능설명서는 [공식 양식](https://drive.google.com/file/d/1mZ5t_w0Rx21QQ5JOQ5uBMgtn0laixkAF/view?usp=sharing)을 사용해야 한다. 임의 양식이나 필수 항목 누락은 심사 대상 제외 사유가 될 수 있다.
- 공공데이터 파일만 사용한 서비스는 인정되지 않는다. 한국관광공사 **OpenAPI 실호출**이 필수다.
- 공지 FAQ는 데이터 동기화와 호출 이력 검증을 위해 실시간 API 호출을 강하게 권고한다. 로컬 DB 저장 방식이 꼭 필요하면 주최 측에 별도 신청 여부를 문의한다.
- 서비스 안의 데이터 출처는 `출처: ⓒ한국관광공사` 또는 `출처: ⓒ한국관광콘텐츠랩`처럼 텍스트로 표시한다. `TourAPI`만 단독으로 표시하거나 공식 CI/BI를 무단 사용하지 않는다.
- 사진·콘텐츠의 저작권과 초상권은 참가자 책임이므로 이미지별 출처와 이용 허락 범위를 검증한다.
- 같은 서비스를 공모전 다른 부문에 중복 출품할 수 없다.
- 개발 서비스가 이용자의 개인 위치를 서버로 전송한다면 위치기반서비스 신고 대상 여부를 [위치정보지원센터](https://www.lbsc.kr/)에 사전 확인한다. 서버로 보내지 않는 구조라도 실제 데이터 흐름을 검토한다.
- 포항 단일 지역 특화는 공식 공지의 지역 특화 기준에 부합한다. 지역 특화 서비스는 1차 심사 가점 대상이다.

이 문서는 내용 초안이다. 제출할 때는 [공식 기능설명서 양식](https://drive.google.com/file/d/1mZ5t_w0Rx21QQ5JOQ5uBMgtn0laixkAF/view?usp=sharing)에 옮겨 작성하고 PDF로 변환한다. 실제 구현·호출이 확인되지 않은 기능과 API는 최종본에서 제외하거나 발전 계획으로 옮긴다.

## 1. 서비스 소개

### 서비스명

POING

### 서비스 유형

반응형 웹 서비스

### 서비스 개요

POING은 포항 여행을 장소 목록이 아니라 하루의 시간 흐름으로 설계한다. 사용자가 동행, 목적, 체류 시간, 이동 수단을 선택하면 포항의 네 권역과 일출·일몰 시간을 함께 고려해 실제로 움직일 수 있는 일정을 만든다. 한국관광공사 OpenAPI로 검증된 장소·운영·이미지 데이터를 추천 근거로 보여주고, 여행 중 변경과 여행 후 기록까지 연결한다.

### 주제 선정 이유

포항은 해맞이, 해안 산책, 시장, 근대문화, 숲과 사찰처럼 시간대와 권역에 따라 경험이 크게 달라진다. 하지만 기존 관광 정보는 장소를 나열하는 데 그쳐 이동 순서와 적절한 방문 시간을 사용자가 다시 판단해야 한다. POING은 포항의 지역성과 시간성을 결합해 정보 탐색 이후의 실제 여행까지 돕기 위해 기획했다.

### 핵심 기능

1. 여행 조건 기반 AI 일정 생성
2. 북포항·구도심·남포항·힐링권역 코스 탐색
3. OpenAPI 기반 추천 근거와 장소 상세 정보
4. 지도 기반 여행 진행과 장소 변경
5. 여행 기록과 피드백을 반영한 다음 추천

### 대표 이미지

- 랜딩 화면의 포항 대표 사진, POING 브랜드 문구, `내 여정 시작하기` 버튼이 함께 보이게 캡처한다.

### 상세 이미지 3~5장

1. 여행 조건 선택과 일출·일몰 정보
2. 포항 권역 지도와 주요 목적지·거리·대중교통
3. 생성 일정과 한국관광공사 장소 사진
4. 추천 근거와 API 활용 정보
5. 여행 진행 또는 여행 기록 화면

## 2. 지역 특화 서비스 구현 세부내용

### 특화 지역

경상북도 포항시

### 구현 내용

- 포항을 북포항, 구도심, 남포항, 힐링권역으로 나눠 이동 부담이 낮은 코스를 제공한다.
- 호미곶, 구룡포, 영일대, 죽도시장, 내연산 등 권역별 대표 장소를 일정의 축으로 사용한다.
- 호미곶의 일출과 해안 노을처럼 방문 시간에 따라 가치가 달라지는 장소를 일정 시간에 반영한다.
- 관광공사 API 연결이 확인된 장소의 주소, 소개, 운영 정보, 대표 이미지를 제공한다.
- 지역별 방문자수와 관광지 집중률 데이터는 실호출과 화면 반영을 확인한 뒤에만 최종 설명서의 활용 항목에 포함한다.
- 목적지 사이 거리와 버스 노선을 함께 표시해 실제 이동 가능한 일정으로 만든다.

## 3. 핵심 기능별 흐름도

### 1. 여행 조건 기반 일정 생성

랜딩 진입 → 여행 시작 → 권역·기간·도착 시간·이동 수단·동행·목적 선택 → 일출·일몰 및 장소 데이터 조회 → 일정 생성 → 일정 확인

### 2. 권역 코스 탐색

권역 코스 선택 → 포항 지도에서 권역 강조 → 주요 목적지 핀과 이동 거리 표시 → 코스 사진과 요약 확인 → 선택 조건에 반영

### 3. 추천 근거 확인

추천 장소 선택 → 관광공사 상세·운영·이미지 데이터 표시 → 방문 데이터와 시간대 근거 확인 → 일정 유지 또는 장소 변경

### 4. 여행 진행과 변경

여행 시작 → 현재 장소와 다음 장소 확인 → 지도·거리·대중교통 확인 → 혼잡 또는 취향에 따라 대체 장소 선택 → 남은 일정 재계산

### 5. 여행 기록과 피드백

방문 완료 → 별점과 한 줄 후기 저장 → 실제 방문 순서와 변경 이력 기록 → 다음 추천의 선호 신호로 반영

## 4. 데이터 활용: 한국관광공사 OpenAPI

| OpenAPI | 활용 내용 |
| --- | --- |
| 국문 관광정보 서비스_GW | 포항 장소 후보, 상세 소개, 주소, 운영 정보, 이미지 |
| 관광사진 정보_GW | 랜딩과 장소 카드의 관광 사진 |
| 관광지별 연관 관광지 API | 다음 장소 및 대체 장소 후보 |
| 관광지 집중률 방문자 추이 예측 API | 시간대별 혼잡도 예측 |
| 빅데이터 지역별 방문자수 API | 권역 및 장소 인기 판단 |

최종 설명서에는 운영 환경에서 실제 호출이 확인된 API만 남긴다. 서비스 화면의 공공데이터 출처는 기관명을 포함해 텍스트로 표기하고 이미지별 이용 조건도 별도로 확인한다.

## 6. 서비스 차별성과 발전 계획

### 서비스 차별성

- 전국 관광지를 넓게 나열하지 않고 포항 한 지역을 권역과 시간대까지 깊게 설계한다.
- 추천에서 끝나지 않고 일정 생성, 근거 확인, 여행 진행, 장소 변경, 기록까지 하나의 흐름으로 연결한다.
- 추천 문장만 보여주지 않고 어떤 공공데이터가 어디에 사용됐는지 사용자가 확인할 수 있다.
- 일출·일몰과 혼잡도처럼 방문 시점에 따라 달라지는 조건을 일정에 반영한다.
- 여행 중 변경과 후기 데이터를 다음 추천에 되돌려 실제 사용으로 더 좋아지는 구조를 갖는다.

### 발전 계획

1. 선택 사항인 운영계정 신청과 데이터 동기화·호출 이력을 유지하는 범위의 응답 성능 개선
2. 실시간 버스 도착과 환승 정보를 활용한 대중교통 일정 고도화
3. 날씨, 지역 행사, 휴무 정보를 반영한 당일 일정 자동 재구성
4. 여행자 유형별 추천 품질 측정과 개인화 모델 개선
5. 다국어 지원 후 경주·울산 등 동해안 인접 지역으로 확장
